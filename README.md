# Taller: Servidor GraphQL con NestJS

Descripción
-----------
Servidor creado usando la API de NestJS y GraphQL. 

Tecnologías principales
----------------------
- Node.js
- TypeScript
- NestJS
- GraphQL(Apollo / Code-first)
- rxjs
- Interceptors de NestJS(AOP / logging)

Persistencia 
-------------
La persistencia se maneja localmente mediante archivos JSON en `dataBase/` para mantener ligereza y fácil de ejecutar.
